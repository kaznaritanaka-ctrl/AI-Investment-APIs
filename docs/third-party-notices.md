# 第三者データの表示

ECB: Source: ECB statistics. 元情報はECBから無償取得可能。原系列と出典metadataを保持する。USD/JPYクロス等はAI-Investment-APIsによる加工計算で、ECBの公表クロスレートではない。[利用方針](https://www.ecb.europa.eu/stats/ecb_statistics/governance_and_quality_framework/html/usage_policy.en.html)と[著作権条件](https://www.ecb.europa.eu/services/using-our-site/disclaimer/html/index.en.html)が適用される。

Models.dev: コミュニティによる二次カタログ。MIT通知は下記LICENSE-models.dev.txtおよびAPI /v1/methodology/licensesに収録し、各観測のreuse.noticeにも同梱する。ロゴ/説明文は転載対象にしない。モデルウェイトのライセンスと価格データのライセンスは別。

本プロジェクト自前コードの配布ライセンスは依頼者未選択。データ全体をMIT/CC0と一括指定しない。依存パッケージはpackage.jsonとpnpm-lock.yamlに固定し、各パッケージのライセンスを保持する。
